MethylGKB · Strata

How Strata works

Methylation-guided responder discovery · live demo at methylkb.vercel.app/strata.html

The 10-second version

"Two patients with the same cancer can respond completely differently to the same drug. Strata reads their DNA's chemical 'settings' and figures out which patients are the responders — automatically. We proved it works by having an AI rediscover a known drug-marker on its own, then go find new ones."

1 What is this?

Your DNA has more than just the genetic code. It also carries chemical tags sitting on top of it — called methylation — that act like dimmer switches, turning genes up or down without changing the underlying code. Two people (or two tumors) with the same diagnosis can have very different dimmer-switch settings. That is a big reason the same drug cures one person and does nothing for another.

Strata is an AI agent that reads those dimmer-switch patterns and finds the hidden group of patients a drug actually works on. You give it a set of samples — each with its methylation readout and how it responded to a drug — and it automatically works out which switches separate the responders from everyone else, names that subgroup, and writes up what it found.

The famous real-world example of this idea: MGMT methylation already tells doctors which brain-tumor patients respond to a specific chemotherapy. One dimmer switch defines a whole treatment decision. The bet behind Strata: there are many more of these buried in the data, and a human can't eyeball them — but an agent can.

2 What question does it answer?

"Inside a disease where a drug only helps some people, who are the responders — and can we spot them ahead of time from their methylation alone?"

And the bigger version: it is not locked to drugs. Swap "drug response" for any outcome — survival, toxicity, disease progression — and it answers the same shape of question: which molecular subgroup is hiding inside this messy population? That is why it ladders up to clinical decision support, not just "a methylation-and-drugs tool."

3 What data does it depend on?

Dead simple — it needs two tables that share an ID:

1. Methylation  —  for each sample, the dimmer-switch reading on each gene
2. An outcome  —  for each sample, what happened (e.g. how well a drug worked)

It joins them on the sample ID and scans. That is it. For the demo we used public data: a database called GDSC — about 1,055 lab-grown cancer cell lines, methylation on ~14,600 genes, paired with how each line responded to 286 drugs. (Plus a set of real leukemia patients for the survival angle.)

Be honest about the scope (so no one catches you out)

This is a proof that the method works, run on lab cell lines and public data — not a finished clinical product. The "new" drug-markers it finds are leads to test, not proven. What makes them credible: the same unbiased scan rediscovered a textbook marker on its own — CDKN2A / MTAP → palbociclib (Pfizer's own drug, Ibrance). If it finds the known answer cold, you trust the new ones more.

4 How can I use it?

  • Just look. Open methylkb.vercel.app/strata.html, click a drug, hit ▶ Run discovery, and watch the agent reason step by step: scan the methylome → rank the markers → name the responder subgroup → check it against known biology → write the brief. (The Palbociclib run is the real live agent; it is recorded so the link works for anyone, no key needed.)
  • Run it yourself. Point the engine at any methylation table + any outcome table, and it returns the responder subgroups and a written brief.
  • The vision. Today it is 2 of 286 drugs; the same loop runs on any methylome-vs-outcome question. At scale — every patient's methylome against every therapy and outcome — it becomes a methylation-guided decision-support layer (and that scale is exactly where the GPU / NVIDIA story kicks in).
One line for the skeptics "It found the known biology by itself before we asked it to find anything new — that's why the new findings are worth a look."
